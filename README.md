# Китобхонаи Шайхул ислом муҷаддид Абу Муҳаммад Маданӣ, алломаи Хуросон

Ин лоиҳаи ибтидоии китобхонаи электронии PDF мебошад. Интерфейс ба забони тоҷикӣ аст.

## Файлҳо
- `index.html` — саҳифаи китобхона
- `manifest.webmanifest` — танзимоти насби PWA
- `sw.js` — service worker барои кэшкунии ибтидоӣ

## Эзоҳ
Ин версияи аввалия аст. Файлҳои PDF дар ин версия танҳо дар дохили ҷаласаи браузер дастрасанд; ҳамоҳангсозии абрӣ ва панели идоракунии китобҳо ҳанӯз илова нашудаанд. Барои истифодаи PWA хостинги HTTPS лозим аст.
